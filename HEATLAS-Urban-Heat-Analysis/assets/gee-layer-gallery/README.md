# GEE layer gallery

Place only authentic screenshots captured from the HEATLAS project in the GEE Code Editor in this folder.

Suggested filenames:

- `01-gee-editor-overview.png`
- `02-jaipur-boundary-and-grid.png`
- `03-daytime-lst.png`
- `04-nighttime-lst.png`
- `05-environmental-indicators.png`
- `06-heat-storage-and-cooling-capacity.png`
- `07-day-night-risk.png`
- `08-mitigation-suitability.png`

For each screenshot, capture the actual map layer, keep the layer name visible where possible, include a legend or document the visualisation range, and record the observation dates in its caption. Hide personal account details and unrelated browser tabs. Do not edit a screenshot in a way that changes or exaggerates the analytical result.
